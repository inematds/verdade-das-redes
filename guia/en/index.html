The truth about social media

17 YouTube channels, Instagram and TikTok accounts, and only one channel truly growing. Instead of selling formulas, we measure everything every week and show what works and what doesn’t.

See the findings View on GitHub
In short

The truth about social media is an open study that brings together real numbers from INEMA channels on YouTube, Instagram, and TikTok. It is for content creators who want to know what really works, based on data rather than guru promises. A bot collects the numbers daily and weekly, matches the same piece of content across all three platforms, and generates a report. If you just want to learn, read the findings. To run it on your own channels, you need Python, a Google Cloud project with the YouTube API enabled, and Claude Code with the Metricool connector for Instagram and TikTok.

What it is

A lab using its own numbers

No “celebrity playbook.” These are our channels, including the wins and failures, measured over time.

📈 Real data

Views, likes, and comments from INEMA’s YouTube channels; views, saves, and shares from 3 brands on Instagram and TikTok.

🔁 Every week

Data collection runs on its own: Instagram and TikTok every day, YouTube every Monday. Each week makes the conclusions more reliable.

🧪 Dated tests

Each change (e.g., no more than 4 Shorts a day) is logged with a start date. A hypothesis becomes a rule only after two weeks of data.

Findings · 07/11/2026

What the numbers have shown so far

The first report, with public YouTube data and Instagram and TikTok metrics.

🎯 The same video, three results

The GitHub Top 10 (a daily series featuring the projects that grew the most on GitHub) got 138,677 views on Instagram (7,354 saves), 460 on TikTok, and 33 on YouTube. eventosextremos’ weather channel (INEMA’s weather forecast channel) shows the opposite: a median of 7,400 on YouTube and ~150 on Instagram.

🧭 Each platform rewards something different

YouTube: what people search for and come back to watch. Instagram: what people save and send to someone. TikTok: what keeps people watching to the end.

⏱️ Posting too much hurts

On eventosextremos, days with 3 or 4 Shorts brought in 17,000 to 31,000 views per video. Days with 8 or 9 dropped to 2,000 to 4,000.

🧩 One topic per channel

The only growing channel sticks to one topic (weather), with a recurring series (“Weather for DD/MM”), a number and location in the title, and a real photo on the cover.

🤖 YouTube AI content is competitive

9 AI channels, 1,520 videos, and only 24 with more than 500 views. What worked: a tutorial that solves a problem (“how to set up Codex,” 1,900 views) and AI for people over 40.

🔎 What people search for

For AI: “what it is,” “for beginners,” “free,” and lists. No one searches for opinionated titles like “Stop…”.

How it works

From data collection to report

Two bots collect the data, a script matches the same piece across all three platforms, and we review the results and decide what to test next.

Metricool: Instagram + TikTok (daily)→ YouTube Data API (every Monday)→ Match the same piece by its YouTube link→ Weekly report→ New dated test
Prerequisites

Run it on your channels

If you just want to learn, read the findings. To measure your own channels, you’ll need the following.

Python 3

The scripts use only the standard library.

# check
python3 --version

Google account for the channel

Access to the Google account that owns the YouTube channel. In step 2, you’ll create authorization in Google Cloud (Google’s developer console, free for this use) that lets the script read only the channel’s numbers.

Claude Code + Metricool (optional)

For Instagram and TikTok only. Metricool is a social media analytics dashboard. You need an account with your social networks connected, Claude Code, and the Metricool MCP connector (the “plug-in” that lets Claude Code read your account), installed as described in Metricool’s help, with a name that has no spaces (e.g., metricool).

# check the connector name
claude mcp list | grep -i metricool

⚠️ Use the youtube.readonly scope. The youtube scope, without “.readonly,” also allows publishing and deleting videos.

Terms: Median = the middle value when you sort views (it isn’t skewed by one video that took off). Piece = the same content published across multiple platforms. Short = a vertical video up to 3 minutes long. Live = a live broadcast. .jsonl = a text file with one record per line.

Step-by-step guide

Measure your channels in 6 steps

Real commands from the repository. Made for Linux.

1

Download the project

Clone the repository and go into its folder.

git clone https://github.com/inematds/verdade-das-redes
cd verdade-das-redes
2

Create YouTube read authorization

Just once, in Google Cloud, signed in with the account that owns the channel:

  1. At the top, “Select a project” → “New project” → give it a name and create it.
  2. “APIs & Services” menu → “Library” → search for YouTube Data API v3 → “Enable.”
  3. “APIs & Services” → “OAuth consent screen” (in newer versions: “Google Auth Platform” → “Audience”): choose “External,” enter a name and email, and add your email under “Test users.”
  4. “APIs & Services” → “Credentials” → “Create credentials” → “OAuth client ID” → choose “Desktop app” → “Download JSON.”
  5. Move the downloaded file (with a name like client_secret_123…apps.googleusercontent.com.json) into the project folder and name it client_secret.json.

Next, from inside the project folder, generate the credentials file. Your browser will open: sign in with the channel account and authorize access. You’ll see “Google hasn’t verified this app”: that’s normal because it’s your app. Click “Advanced” → “Go to (unsafe)” and then “Continue.” The script requests read-only access.

mv ~/Downloads/client_secret_*.json client_secret.json
python3 coleta/autorizar.py client_secret.json ~/minhas-credenciais.json
# Credentials saved in /home/voce/minhas-credenciais.json

While the app is in test mode, Google makes the authorization expire after 7 days: run the last command again or publish the app on the consent screen.

Now tell the script where each channel is. Have more than one channel? Repeat for each one, with a different name and file.

cat > ~/verdade-canais.json <<'FIM'
{"canais": {"meucanal": {
  "credenciais_cmd": "cat ~/minhas-credenciais.json"}}}
FIM
export VR_CONFIG=~/verdade-canais.json  # only applies in this terminal; to make it permanent: add the line to ~/.bashrc
3

Collect YouTube data

Fetches everything each channel published in the last 60 days (or the number in VR_DIAS), including views, likes, and comments, and separates Shorts, long videos, and Lives.

python3 coleta/youtube.py
# ok meucanal: 1200 inscritos, 85 vídeos em 60 dias
# 85 vídeos -> dados/youtube/AAAA-MM-DD.jsonl
VR_DIAS=30 python3 coleta/youtube.py meucanal  # only 30 days
4

Collect Instagram and TikTok data (optional)

Use the Metricool connector in Claude Code. First, find your brand ID: in Claude Code, ask it to “call getBrandSettings from the Metricool connector” and note the id. Then run it with the ID and connector name. The brand name must not contain spaces (hyphens are fine).

VR_MCP=metricool VR_MARCAS="1234567:minhamarca" bash coleta/metricool.sh
# grava dados/metricool/AAAA-MM-DD/minhamarca-tiktok.json etc.
5

Generate the weekly report

Builds a table of numbers: median by channel and format, posts per day versus views, and the same piece across all three platforms. Matching across platforms works only if the Instagram/TikTok post text includes the YouTube video link (e.g., “On YouTube: https://youtube.com/shorts/…”). The findings above come from someone reviewing these tables and testing hypotheses; the script doesn’t write conclusions on its own.

python3 coleta/junta.py  # relatorios/semana-AAAA-MM-DD.md
6

Run it automatically (optional)

Without scheduling, you can run steps 3 to 5 manually whenever you want. To automate them, use cron: Instagram and TikTok every day at 6:30 a.m.; YouTube and the report every Monday at 7 a.m. Run crontab -e: it opens a text editor. Paste the two lines below at the end of the file, save, and close (in nano: Ctrl+O, Enter, Ctrl+X). Replace ~/verdade-das-redes with the folder where you cloned the project.

# lines to paste inside crontab -e
30 6 * * *  cd ~/verdade-das-redes && VR_MCP=metricool VR_MARCAS="1234567:minhamarca" bash coleta/metricool.sh
0 7 * * 1  cd ~/verdade-das-redes && VR_CONFIG=~/verdade-canais.json python3 coleta/youtube.py && python3 coleta/junta.py
