Em resumo

A verdade das redes é um estudo aberto que junta os números reais dos canais da INEMA no YouTube, no Instagram e no TikTok. Serve para quem cria conteúdo e quer saber o que funciona de verdade, com dados, e não com promessa de guru. Um robô coleta os números todo dia e toda semana, junta a mesma peça nas três redes e gera um relatório. Para só aprender, basta ler os achados. Para rodar nos seus canais, você precisa de Python, de um projeto no Google Cloud com a API do YouTube ligada e, para Instagram e TikTok, do Claude Code com o conector do Metricool.

O que é

Um laboratório com os próprios números

Nada de "playbook de celebridade". São os nossos canais, com os acertos e os fracassos, medidos com data.

📈 Dados reais

Views, likes e comentários dos canais da INEMA no YouTube; views, salvamentos e compartilhamentos de 3 marcas no Instagram e no TikTok.

🔁 Toda semana

A coleta roda sozinha: Instagram e TikTok todo dia, YouTube toda segunda. Cada semana deixa as conclusões mais firmes.

🧪 Testes com data

Cada mudança (ex.: no máximo 4 shorts por dia) entra com data de início. Hipótese só vira regra com duas semanas de números.

Achados · 07/11/2026

O que os números já mostraram

Primeiro relatório, com dados públicos do YouTube e métricas do Instagram e do TikTok.

🎯 O mesmo vídeo, três resultados

O Top 10 do GitHub (série diária com os projetos que mais cresceram no GitHub) teve 138.677 views no Instagram (7.354 salvamentos), 460 no TikTok e 33 no YouTube. O clima do eventosextremos (canal de previsão do tempo da INEMA) faz o contrário: mediana de 7.400 no YouTube e ~150 no Instagram.

🧭 Cada rede premia uma coisa

YouTube: o que as pessoas procuram e voltam para ver. Instagram: o que se salva e se manda para alguém. TikTok: o que prende até o fim.

⏱️ Postar demais derruba

No eventosextremos, dias com 3 ou 4 shorts renderam de 17 a 31 mil views por vídeo. Dias com 8 ou 9 caíram para 2 a 4 mil.

🧩 Um assunto por canal

O único canal que cresce fala de um tema só (clima), com série fixa ("Clima do dia DD/MM"), número e lugar no título e foto real na capa.

🤖 IA no YouTube é disputada

9 canais de IA, 1.520 vídeos, só 24 passaram de 500 views. O que funcionou: tutorial que resolve um problema ("como configurar o Codex", 1.900) e IA para quem tem 40+.

🔎 O que as pessoas procuram

Em IA: "o que é", "para iniciantes", "grátis" e listas. Ninguém procura título de opinião como "Pare de…".

Como funciona

Da coleta ao relatório

Dois robôs coletam, um script junta a mesma peça nas três redes, e a gente lê e decide o próximo teste.

Metricool: Instagram + TikTok (todo dia)→ YouTube Data API (toda segunda)→ Junta a mesma peça pelo link do YouTube→ Relatório da semana→ Novo teste com data
Pré-requisitos

Para rodar nos seus canais

Para só aprender, leia os achados. Para medir os seus canais, você precisa disto.

Python 3

Os scripts usam só a biblioteca padrão.

# conferir
python3 --version

Conta Google do canal

Acesso à conta Google dona do canal no YouTube. No passo 2 você cria, no Google Cloud (o painel de desenvolvedor do Google, gratuito para este uso), a autorização que deixa o script só ler os números do canal.

Claude Code + Metricool (opcional)

Só para Instagram e TikTok. O Metricool é um painel de métricas de redes sociais. Você precisa de uma conta com as redes ligadas, do Claude Code e do conector MCP do Metricool (o "plugue" que deixa o Claude Code ler a sua conta), instalado como o Metricool explica na ajuda dele, com um nome sem espaços (ex.: metricool).

# conferir o nome do conector
claude mcp list | grep -i metricool

⚠️ Use o escopo youtube.readonly. O escopo youtube, sem ".readonly", também deixa publicar e apagar vídeos.

Termos: mediana = o valor do meio quando você põe as views em ordem (não é puxada por um vídeo que estourou). Peça = um mesmo conteúdo publicado em várias redes. Short = vídeo vertical de até 3 minutos. Live = transmissão ao vivo. .jsonl = arquivo de texto com um registro por linha.

Guia de uso · passo a passo

Medir os seus canais em 6 passos

Comandos reais do repositório. Feito para Linux.

1

Baixe o projeto

Clone o repositório e entre na pasta.

git clone https://github.com/inematds/verdade-das-redes
cd verdade-das-redes
2

Crie a autorização de leitura do YouTube

Uma vez só, no Google Cloud, entrando com a conta dona do canal:

  1. No topo, "Selecionar projeto" → "Novo projeto" → dê um nome e crie.
  2. Menu "APIs e serviços" → "Biblioteca" → procure YouTube Data API v3 → "Ativar".
  3. "APIs e serviços" → "Tela de permissão OAuth" (em versões novas: "Google Auth Platform" → "Público-alvo"): tipo "Externo", preencha nome e e-mail e, em "Usuários de teste", adicione o seu e-mail.
  4. "APIs e serviços" → "Credenciais" → "Criar credenciais" → "ID do cliente OAuth" → tipo "App para computador" → "Fazer download do JSON".
  5. Mova o arquivo baixado (nome parecido com client_secret_123…apps.googleusercontent.com.json) para a pasta do projeto com o nome client_secret.json.

Depois, dentro da pasta do projeto, gere o arquivo de credenciais. Abre o navegador: entre com a conta do canal e autorize. Vai aparecer "O Google não verificou este app": é normal, porque o app é seu. Clique em "Avançado" → "Acessar (não seguro)" e depois em "Continuar". O script já pede só permissão de leitura.

mv ~/Downloads/client_secret_*.json client_secret.json
python3 coleta/autorizar.py client_secret.json ~/minhas-credenciais.json
# Credenciais gravadas em /home/voce/minhas-credenciais.json

Com o app em modo de teste, o Google faz a autorização vencer em 7 dias: rode o último comando de novo, ou publique o app na tela de permissão.

Agora diga ao script onde está cada canal. Tem mais de um canal? Repita para cada um, com outro nome e outro arquivo.

cat > ~/verdade-canais.json <<'FIM'
{"canais": {"meucanal": {
  "credenciais_cmd": "cat ~/minhas-credenciais.json"}}}
FIM
export VR_CONFIG=~/verdade-canais.json  # vale só neste terminal; para sempre: ponha a linha no ~/.bashrc
3

Colete o YouTube

Busca tudo o que cada canal publicou nos últimos 60 dias (ou o número em VR_DIAS), com views, likes e comentários, e separa short, vídeo longo e live.

python3 coleta/youtube.py
# ok meucanal: 1200 inscritos, 85 vídeos em 60 dias
# 85 vídeos -> dados/youtube/AAAA-MM-DD.jsonl
VR_DIAS=30 python3 coleta/youtube.py meucanal  # só 30 dias
4

Colete o Instagram e o TikTok (opcional)

Pelo conector do Metricool no Claude Code. Primeiro descubra o ID da sua marca: no Claude Code, peça "chame getBrandSettings do conector do Metricool" e anote o id. Depois rode com o ID e o nome do conector. O nome da marca vai sem espaço (hífen pode).

VR_MCP=metricool VR_MARCAS="1234567:minhamarca" bash coleta/metricool.sh
# grava dados/metricool/AAAA-MM-DD/minhamarca-tiktok.json etc.
5

Gere o relatório da semana

Monta a tabela de números: mediana por canal e formato, posts por dia contra views e a mesma peça nas três redes. A ligação entre redes só funciona se o texto do post no Instagram/TikTok tiver o link do vídeo no YouTube (ex.: "No YouTube: https://youtube.com/shorts/…"). Os achados acima saem de alguém lendo essas tabelas e testando hipóteses; o script não escreve conclusões sozinho.

python3 coleta/junta.py  # relatorios/semana-AAAA-MM-DD.md
6

Deixe rodando sozinho (opcional)

Sem agendar, você roda os passos 3 a 5 à mão quando quiser. Para automatizar, use o cron: Instagram e TikTok todo dia às 6h30, YouTube e relatório toda segunda às 7h. Rode crontab -e: ele abre um editor de texto. Cole as duas linhas abaixo no fim do arquivo, salve e feche (no editor nano: Ctrl+O, Enter, Ctrl+X). Troque ~/verdade-das-redes pela pasta onde você clonou.

# linhas para colar dentro do crontab -e
30 6 * * *  cd ~/verdade-das-redes && VR_MCP=metricool VR_MARCAS="1234567:minhamarca" bash coleta/metricool.sh
0 7 * * 1  cd ~/verdade-das-redes && VR_CONFIG=~/verdade-canais.json python3 coleta/youtube.py && python3 coleta/junta.py
